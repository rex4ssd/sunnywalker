Family app shelf review note

The Settings screen includes a rexcode family app shelf behind the parental gate.
It only lists our own child-friendly apps. If another app is already installed,
the shelf opens it with a registered custom URL scheme. If it is not installed,
the parent gate must be completed before the app can show an App Store product
page using SKStoreProductViewController. No third-party advertising, tracking,
or external web content is used.
