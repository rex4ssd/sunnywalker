## Description

**zh-Hant**
```
孩子聽到的不是刺耳鬧鈴，是爸媽溫柔的聲音 ☀️

SunnyWalker 是專為孩子設計的兒童鬧鐘。錄下一句「寶貝，起床囉！」，
明天早上，孩子就會在你的聲音中醒來——即使你還在廚房忙早餐。

【為什麼孩子需要自己的鬧鐘】
賴床、起床氣、每天上學前的拉鋸戰……
讓孩子擁有「自己的鬧鐘」，是養成自主起床習慣的第一步。
聽到的是爸媽的聲音，起床就不再是命令，而是溫柔的約定。

【主要功能】
‧ 爸媽錄音當鈴聲：你的聲音就是孩子的專屬鬧鈴，鎖定畫面也能響
‧ 兩種響鈴模式，依孩子選擇：
　－ 系統鬧鐘：持續響直到關閉，深睡的孩子也叫得醒
　－ 溫和提醒：響 30 秒自動安靜，適合午睡、寫功課等輕提醒
‧ 口令關閉：要說出指定的句子才能關鬧鐘，確認孩子真的醒了
‧ 起床紀錄：每天幾點起床一目了然，看得見孩子的進步
‧ 療癒插畫風格：可愛角色陪孩子開啟每一天
‧ 支援繁體中文與英文

【爸媽可以放心】
‧ 專為兒童設計（Made for Kids）
‧ 無廣告
‧ 不收集任何個人資料

每天早晨，讓孩子在你的聲音裡醒來。
下載 SunnyWalker，告別起床氣，迎接陽光 
```
