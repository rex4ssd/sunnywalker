```
- 支援動態字級，把字放大也不會破版
```

**en**（約 1,180 characters）

```
One phone, a separate set of alarms for each child

GROUPS
- Split alarms per child (Brother, Sister, and so on) and swipe left or right on the home screen to switch
- Each child can have their own mascot, shown when you swipe to their list
- New Sunflower mascot: drop your own photo into the flower's center, then drag and pinch to fit

- Slimmer alarm cards on the home screen, so you see more at a glance
- Dynamic Type supported: larger text no longer breaks the layout

Core wake-up features are always free. Fully offline, no ads, no data collection.
```

## Review Notes（App Review Information → Notes）

> Made for Kids + 已上架 IAP。沿用既有說明，加上本版新功能的逐段交代。

```
SunnyWalker is a children's alarm clock. This update adds per-child alarm groups, a spoken time chime, and to-do voice reminders. Everything runs on device.

1. Privacy: no accounts, no analytics, no third-party SDKs, no ads. Nothing the child records or the parent adds ever leaves the device. Recordings are stored in the app's own container and can be deleted in the app.

2. Parental gate: Settings, adding or editing an alarm, pausing a group, and the Pro purchase are all behind a multiplication question that children in the target age range cannot solve.

3. In-app purchase: SunnyWalker Pro is a one-time non-consumable that removes the free limits. It is offered only after the parental gate and is handled entirely by StoreKit.

4. Custom photo: the Sunflower mascot lets a parent place a photo in the flower's center using PhotosPicker, which runs out of process, so the app never requests photo library access and never reads the library itself.

5. To-do voice reminders: the parent records the reminder. The child only listens and confirms; no microphone access is needed for playback.
```
