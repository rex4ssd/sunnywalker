# v1.4.20260814（build 18）Release Note

> ASC 要貼的文案在 `../docs/for_Apple_store/appstoreconnect_content_260814.md`。
> 本檔是內部紀錄：這版做了什麼、為什麼、以及哪些是合規敏感點。
> 前一版（已上架）：1.3.20260615 build 17 — SunnyWalker Pro，2026-08-11 通過審核。

## 這版的主軸

**一台手機服務全家小朋友。** 鬧鐘依小朋友分組（各自的清單與吉祥物），並補上兩種
新的提醒型態（報時、待辦語音），同時把免費版可設定的數量從 6 個放寬到 10 個。
另外修掉一個會直接毀掉「爸媽聲音」賣點的雷：**App 更新後自訂鈴聲會退成系統「咚」一聲**。

## 功能

### 多人鬧鐘（分組）（本版新增）

一台手機分成多位小朋友各自的鬧鐘清單、各自的吉祥物；首頁左右滑切換，
點群組名稱可把整組暫停（過家長閘）。

**為什麼用「集中的響鈴閘」而不是連動每顆鬧鐘的 `isEnabled`：**
群組關閉時若去把每顆鬧鐘的 `isEnabled` 設 false，重新開啟群組就無法還原
「原本個別被關掉的那幾顆」。所以改成一道 nonisolated 的 `AppSettings.groupAllowsFiring(_:)`
（直接讀 UserDefaults），設在所有實際排程決策點：`AlarmScheduler.schedule`、
`AlarmKitService.syncAllEnabled` / `syncAlarm`、`HomeView.checkForegroundAlarm`、
通知模式前景補排、背景聆聽 snapshot。順手修掉「縮小群組數量後、被隱藏的群組仍會響」。

**資料相容：** `Alarm.groupIndex` 是 optional（SwiftData 輕量遷移安全），
舊鬧鐘 nil → 群組 A，升級後行為完全不變。

### 自訂「向日葵」吉祥物（本版新增）

花心可放家長自己的照片，拖曳＋雙指縮放對位，`ImageRenderer` 所見即所得存檔。

🔴 **合規：用 `PhotosPicker`（out-of-process）→ 不需要 `NSPhotoLibraryUsageDescription`、
不會跳相簿權限、App 全程讀不到相簿。** Kids 分類下這是關鍵取捨：寧可少一點彈性，
也不要在兒童 App 裡出現相簿權限對話框。

### 報時鬧鐘（本版新增）

群組設定列的鈴鐺開關打開後，該組鬧鐘改為報時：時間到用語音念出時刻，可設連報次數。
中／英跟隨 App 語言。走通知模式、響一次自動停。

**踩過的雷（已修）：** 舊版把「連報 N 次」烤進同一個聲音檔 → 檔案變長 →
iOS 把過長的自訂通知音**整顆退成約 2 秒的預設音**（count=2 就已 5.4s 中招）。
現在改成「單句短檔 + 多顆通知堆疊」，並在 `AlarmScheduler` 內建舊檔偵測自動重合成。

### 待辦語音提醒（本版新增）

群組設定列的氣球開關打開後，該組可錄一段提醒語音、挑圖示與顯示時長；時間到在主頁
吉祥物旁冒出圖示，孩子點一下播放、聽完長按確認收起，家長可在「待辦紀錄」看到已接收。

🔴 **合規：待辦不發通知、不進 AlarmKit**，只在 App 前景冒圖示 —— 所以它不會在
鎖屏吵人，也不需要額外的通知權限敘述。錄音是**家長**錄的，孩子端只有播放，不開麥克風。

### 免費版上限 6 → 10（本版變更）

免費版可設定總量（鬧鐘＋待辦合計、不分群組）從 6 提到 10；Pro 維持無上限。
上限統一由首頁「＋」鈕以總量把關，不再有獨立的待辦上限。

### App 更新後鈴聲變「咚」一聲（本版修正）

**症狀：** 更新 App 後舊鬧鐘設定都在、也照響，但自訂鈴聲變成系統預設提示音。

**Root cause：** 更新會把 bundle 與 app container 搬到新的 UUID 路徑；更新**前**排進
系統的 AlarmKit 條目、pending 通知、以及 sound server 的「檔名→路徑」快取仍握著舊路徑。
自訂音解析失敗時 iOS 一律**靜默** fallback 成預設音。**同名重寫檔案繞不過快取**
（sound server 以檔名為 key），必須換新檔名。

**修法：** `AlarmSoundUpgradeHealer` 偵測 `CFBundleVersion` 變更 → 每顆鬧鐘的聲音檔
用新的 epoch 檔名重匯出（錄音／內建鈴聲／報時三種路徑都涵蓋）→ 交給既有流程重排。
順帶修三種舊資料組合（`soundFileName` 是錄音 CAF 但 `recordingName` 空／錄音已刪／
選了內建卻殘留 `recordingName`），這些組合會讓排程分支雙雙不成立而**永遠**是預設音。

⚠️ **無法涵蓋的邊界：** 更新完、**還沒開過 App 之前**就響的那一顆救不了 ——
修復是 App 的程式碼，而 App 在被打開之前不會執行任何一行；那一響仍是預設音，
開一次 App 之後全部痊癒。已在 What's New 用「修正：更新 App 之後…」平實描述，不做保證。

### 錄音介面精準時長（本版新增）

錄音中顯示 `分:秒`（免費版併顯 `/ 3:00` 上限），錄完顯示**實際檔案長度**（量 m4a，
不是 UI 計時器）。全 app 的 `分:秒` 格式統一成 `TimeInterval.minSecString`
—— 先前語音庫用 floor、錄音頁用 round，同一段 4.7 秒錄音會顯示 0:04 vs 0:05。

### 溫和提醒「切段間隔」可調（本版新增）

切段（把語音用多顆通知堆到約 30 秒）的段間隔獨立成 `burstGapSeconds`（1 或 2 秒，
預設 2＝原行為），住在設定頁、與循環播放間隔並列。

**為什麼要獨立：** 原本沿用 `recordingGapSeconds`，但那顆同時控制 App 內響鈴的
循環節奏 —— 為了實測而調間隔會連帶改掉響鈴體驗。
**為什麼放設定頁而不是鬧鐘編輯器：** 編輯器所有欄位都是暫存、按「儲存」才生效，
全域設定放進去會造成「按了取消卻改到東西」。

**動機（未結案的觀察）：** Rex 手上多台裝置偶爾出現「切段鬧鐘沒聲音」。這版加了
`🔬 BurstPlan` 診斷 log（baseline 時刻＋每顆 offset＋間距組成＋實排/計畫顆數＋
pending 數＋聲音檔名；被 64 顆上限截斷時另印 TRUNCATED），配合 1s/2s 對照做實機定位。
**下一版再依實測結果決定要不要改預設值。**

### 其他

- 首頁鬧鐘卡片高度約 −30%，一頁看到更多。
- 響鈴診斷：把「實際響幾聲／多久」記進起床紀錄，供上面那條沒聲音的問題比對。
- 支援 Dynamic Type（放大字級不破版）、VoiceOver 朗讀修正。
- 新增開源致謝畫面（ConfettiSwiftUI 的 MIT 標示義務）。
- 設定頁加「關於」版本資訊（版本／build／首次啟動）。

## 🔴 隱私口徑變更

**無變更。** 本版新增的功能全部在裝置上完成：分組與吉祥物是本機設定、向日葵照片
用 out-of-process 的 PhotosPicker 且只存自己的 container、報時是本機語音合成、
待辦錄音與播放都在本機。「完全離線、零廣告、不收集任何資料」的口徑**仍然成立**，
ASC 文案沿用即可。
