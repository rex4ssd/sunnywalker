# 小孩錄音功能
技術架構與隱私策略 (CloudKit 是首選)
這項功能意味著 App 需要跨裝置同步（從小孩的設備傳到家長的手機）。

零伺服器成本與高隱私： 強烈建議採用 Apple 的 CloudKit 來實作。將錄音檔直接同步到用戶家庭群組的 iCloud 空間。這樣不僅能省下您建置後端伺服器與儲存空間的成本，資料完全掌握在使用者手裡，更能完美解決兒童隱私與資安合規的問題。


#時空膠囊語音 (Voice Time Capsule)
為了讓這個功能更穩定且具有吸引力，建議採取以下實作策略：

在地化排程 (Local Scheduling)： 透過 iOS 的 UNUserNotificationCenter 結合本機時間判斷，即可在指定日期播放音檔，這完全不需要後端伺服器運算，能最大化節能與隱私。

視覺化介面： 在 App 內做一個「時空信箱」的 UI，讓孩子看到自己存了多少則「未來的訊息」。這能提高 App 的使用黏著度，家長也會因為這些珍貴的成長紀錄而更願意付費支持。

## Fable 補充（2026-06-12）

### Pro v1 — US$1.99 終身（code 已有 FeatureLimits 開關，flip isPro 即生效）
- 鬧鐘數 6 → 無上限（`maxAlarms`）
- 自定鈴聲庫 5 則 → 無上限（`maxVoiceClips`）
- 單則自定鈴聲 5s → 30s（`maxVoiceClipSeconds`；⚠️ 你上面筆記寫 15s、code 既定 30s — 建議照 code 用 30s，US$1.99 終身給大方一點；要改 15s 只動 FeatureLimits 一行）
- 每鬧鐘家長錄音 180s → 無上限（`maxAlarmRecordingSeconds`）
- 原則：**免費版現有功能一個都不鎖**（Lode 教訓：鎖既有功能 = 1 星負評 + Apple 觀感差）

### Pro 加值 — 之後免費追加給 Pro 用戶，墊高 lifetime 價值感、不用漲價
- 新增「Pro 專屬吉祥物 / 場景主題」：新做的才鎖 Pro，現有 5 隻維持免費
- Alternate app icons：小孩自選 app 圖示（純 client，工小）
- 起床紀錄進階：連續起床 streak、月曆視圖、簡單統計圖
- 多孩子 profile：每個小孩自己的鬧鐘組＋起床紀錄（家裡兩寶以上的剛性需求）
- per-alarm 吉祥物 / 顏色
- 睡前床邊故事（你新加的）→ 適合 Pro：內建免費 2-3 則、Pro 解鎖全部＋家長自錄故事不限長度；搭配既有床邊模式（BedSideManager）很順

### Future（原筆記項目的定位建議）
- 時空膠囊語音 → 最適合當 Pro 招牌功能，local scheduling 免後端，優先做
- 小孩錄音 CloudKit 家庭同步 → Pro v2；Kids Category 隱私要再過一次合規（iCloud 同步仍算 user data 離機）
- Line 設定語音/時間 → 需後端＋第三方，Made for Kids 幾乎無法過審，放最後或放棄
- 成長聲音自動剪輯 → Pro 加值好題材，純 on-device 可行

### 不建議
- 把現有免費功能（5 隻吉祥物、匯入匯出、起床紀錄基本版）移進 Pro
- 訂閱制：US$1.99 終身先驗證付費意願；kids app 上訂閱觀感差、退訂客訴多
- 消耗型點數：與「一次買斷給家長安心」的定位衝突
